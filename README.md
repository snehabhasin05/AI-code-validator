# AI Code Validator

A simple AI code validator web app.

🔗 **Live Demo**: [Click here to visit](https://ai-code-validator.vercel.app/)

## Features
- Upload and validate your code
- HTML interface 

## How to Use
1. Open the website.
2. Paste or upload your code.
3. See the results instantly.

## Technologies Used
- HTML
- CSS
- JavaScript
- Vercel (for deployment)
